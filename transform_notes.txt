t_intersection_list intersect_unit_sphere_world(t_ray *ray);

Ray–sphere intersect for a unit sphere centered at the origin in world space.

Used when the sphere has no transform (fast path).

t_intersection_list intersect_sphere_object_space(t_ray *ray_obj);

Same math, but assumes a unit sphere at origin in object space.

Called after you’ve transformed the ray with the sphere’s inverse matrix.

void fill_intersection_points_world(t_intersection_list *hits, t_ray *ray_world);

Given t values (already computed) and the world-space ray, fills .point for each intersection in world space.

Sphere helpers
t_ray world_to_object_ray(t_ray *ray_world, t_mat *inv_transform);

Takes a world-space ray and an inverse matrix, returns the ray in object space.

t_intersection_list intersect_sphere_transformed(t_sphere *sphere, t_ray *ray_world);

Uses world_to_object_ray, then intersect_sphere_object_space, then fill_intersection_points_world.

Public entry point
t_intersection_list intersect_sphere(t_sphere *sphere, t_ray *ray_world);

If !sphere->is_transformed, calls intersect_unit_sphere_world.

Otherwise calls intersect_sphere_transformed.

Projection / rendering
void project_sphere(t_system *sys, mlx_image_t *img);

Stays almost exactly as you have it now, but calls the unified
intersect_sphere(&sys->obj_list[0].sphere, &ray);

The branching between unit-sphere and transformed sphere happens inside intersect_sphere, not in project_sphere.
